Setup Checklists

Printable one-pagers. Use whichever brand's section applies to you. Cross off items — that's how humans remember things.

Universal checklist (before any brand)

Wi-Fi name and password written down and accessible (not on the router)
Phone or tablet charged, connected to the same Wi-Fi
Right account ready (Amazon / Google / Apple ID)
Speaker plugged in and lit up
Right app installed and signed in
Speaker found in app and connected to Wi-Fi
Room / location assigned
Voice profile set up for you
First test phrase worked ("what's the weather")
App icon on the home screen

Privacy follow-up (15 minutes, one time)

Old voice recordings deleted (all brands: see privacy)
"Help improve the product" / "Share recordings" options OFF
Auto-delete old recordings set to 3 or 18 months
Voice purchasing OFF or PIN set
Mic mute button located (find it once, know where it is forever)
Household members list reviewed

Alexa-specific checklist

Alexa app installed, signed in to the right Amazon account
Speaker connected, room named
Voice ID enrolled for you (and each family member you want recognized)
Voice Purchasing: off, PIN, or reorder-only (pick one)
Family members: Voice Purchasing off for kids
Drop In: off (unless you want it)
Skills installed: only ones you actually recognize by name
First routine made ("Good morning")
Do Not Disturb hours set if needed (bedroom speakers)
Explicit language filter on if kids in the house

Google-specific checklist

Google Home app installed, signed in to the right Google account
Speaker connected, room named
Voice Match enrolled for you (and each family member)
Household members reviewed and pruned
Voice purchases: off or PIN
Digital Wellbeing set for kids (kid account, explicit filter off)
First routine made ("Good morning")
Ad personalization off (if that matters to you)
Web & App Activity auto-delete set to 3 months

HomePod (Siri) checklist

iPhone updated (HomePod requires a recent iOS)
HomePod plugged in and paired in the Home app
"Hey Siri" turned on for each iPhone in the home (so voice recognition per-person works)
Personal Requests turned on (so calls/texts/reminders come through)
Apple Music subscription confirmed (or use AirPlay from any phone)
Shortcuts app routine made for "hey Siri, morning routine"
Share Audio Recordings OFF (privacy)
Voice purchasing set up or verified OFF
